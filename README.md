# Expense Tracker (private PWA)
Minimal expense tracker. All data stays on your phone. Open `index.html` through GitHub Pages: https://YOUR-USERNAME.github.io/expense-tracker/
To change the app, give `HANDOFF.md` and `index.html` to an AI assistant (see the prompt at the top of HANDOFF.md), upload the new files here, and bump the version in `sw.js`.
